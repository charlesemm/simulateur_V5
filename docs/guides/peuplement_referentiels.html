1. Ce qu'est une table référentielle ici

Le simulateur transpose les 317 tables du dictionnaire Oracle de Mirka sous le préfixe TB_SIM_. Celles dont le nom Mirka commence par TB_REF_ ou TB_TV_ sont les référentiels (règle de tools/generer_tables_sim.py) : elles décrivent le monde, sont partagées par toutes les simulations et ne portent pas de SIMULATION_ID. Les 219 autres sont des tables de faits, cloisonnées par exécution.

  • TB_SIM_TV_* (tables de valeurs) : nomenclatures courtes, code + dénomination — genres, régimes, statuts, types, localisation, support…
  • TB_SIM_REF_* (référentiels métier) : catalogues volumineux — centres de santé, médicaments, actes médicaux, pathologies, professionnels de santé, collectivités.

2. Règles communes de peuplement

Colonnes d'audit. DATE_CREATION, UTILISATEUR_ID_CREATION, DATE_MODIFICATION, UTILISATEUR_ID_MODIFICATION ouvrent chaque table. Seule DATE_CREATION a un défaut (now()) : UTILISATEUR_ID_CREATION est NOT NULL sans défaut et doit toujours être fourni (par exemple 'SEED'). Les deux colonnes de modification restent nulles à la création.
Clés historisées. 95 tables ont une date de début dans leur clé primaire (*_DATE_DEBUT, défaut now()). La ligne en vigueur a *_DATE_FIN nulle. Pour deux versions d'un même code, clôturez l'ancienne en renseignant sa date de fin, puis insérez la nouvelle avec une autre date de début. Pour un seed reproductible, fixez la date de début plutôt que d'accepter now().
Liens entre référentiels. Il n'y a que 6 clé(s) étrangère(s) dans le périmètre : la plupart des liens (région → département → localité, par exemple) ne sont pas contraints en base. Ils reposent sur les codes que vous écrivez, et une faute de saisie ne sera pas rejetée. Vérifiez l'intégrité vous-même après chargement.
Clés primaires. Aucune séquence : le simulateur insère des clés explicites. Vous devez fournir chaque code.
Exception à connaître. TB_SIM_REF_PROFESSIONNELS_SANTE dépend de TB_SIM_ASSURES (table de faits). Ces tables ne se chargent qu'après les assurés correspondants, et suppriment en cascade.
